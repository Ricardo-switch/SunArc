# SunArc, kanaal beta

Deze tak maakt de CI zelf, na elke groene versie op `beta` (besluit 336).
Hij bevat alleen wat de add-on-winkel van Home Assistant leest. De code
staat op de tak `beta`; de gewone add-on staat op `main`.

Toevoegen in Home Assistant: Instellingen › Add-ons › Add-on-winkel ›
rechtsboven › Repositories, met dit adres:

    https://github.com/Ricardo-switch/SunArc#addon-beta
